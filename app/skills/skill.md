# 口播稿拆句（video-script-splitter）

## 1. 目标

把用户提供的一整段口播稿按**句子**切分，输出一份可直接使用、可直接朗读的 `.txt`：

- 一句一行；
- 句与句之间空一行；
- 句内逗号、顿号、分号、冒号等分段标点后固定加 **四个半角空格**；
- `--` 等语义分隔符处同样切句。

核心原则：**只做切分与排版，不改写原文、不增删内容、不纠正语病。**

## 2. 触发条件

出现以下任一情况时使用本技能：

- 用户给出整段口播稿，要求“拆句 / 断句 / 分段 / 排版 / 导出 txt”；
- 用户要求句间空行、标点后加空格等朗读排版；
- 用户要求把带 `--` 的稿子拆成独立句子；
- 用户为配音、口播、字幕准备逐句文本。

## 3. 不适用场景

- 润色、改写、扩写、缩写文案；
- 核实事实、数据、版权；
- 生成分镜、视频、配音文件；
- 输入只是关键词或提纲，不是完整口播稿。

遇到不适用场景，先说明本技能只做切句与排版。

## 4. 输入约定

必填：

- `script`：整段口播稿纯文本，允许有换行、空行、标点缺失。

可选：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `output_dir` | `state/output` | txt 输出目录 |
| `keep_script_marks` | `true` | 是否保留“【停顿】”等口播提示标记；默认保留 |
| `space_width` | `4` | 句内标点后插入的空格数，默认 4 个半角空格 |

未指定时使用默认值，不追问。

## 5. 输出约定

- 文件格式：UTF-8 纯文本 `.txt`，扩展名必须是 `.txt`；
- 文件名：`script_split_YYYYMMDD_HHMMSS.txt`；
- **文件内容只包含处理后的口播文本**：不写标题、段号、统计、解释、Markdown 标记；
- 每个句子独占一段；
- 相邻句子之间**恰好一个空行**（即两个换行符）；
- 句内标点后**恰好四个半角空格**（U+0020 × 4），不要用全角空格或制表符；
- 句末标点（`。！？!?` 等）保留在原句末尾，其后再空一行；
- 在聊天通道中回复时，只返回：文件路径、句子数、原始字数，不把全文刷屏；
- 无法写文件时，在回复中给出完整 txt 内容，并说明未落盘。

## 6. 处理规则

### 6.1 预处理

1. 去掉全文首尾空白；
2. 将连续空格、制表符、换行、空行统一视为一个空白分隔；
3. 不删除原文用词、数字、英文、专有名词、标点；
4. 默认保留“【停顿】”“（镜头切近）”“BGM 起”等口播提示标记；
5. 不纠正错别字，不调整语序，不改写句子。

### 6.2 切句

以下位置视为句子边界，切分后保留句末标点：

- 中文句末标点：`。`、`！`、`？`、`…`（连续省略号按一个句末处理）；
- 英文句末标点：`!`、`?`、`. `（点号后跟空格或位于文末时；小数点、缩写、网址中的点不切）；
- 语义分隔符：`--`（两个及以上连续半角连字符）和 `——`（中文破折号）。

具体处理：

1. 在 `--` / `——` 处切句，并**删除该分隔符及其两侧空白**；
2. 连续多个 `--` 只产生一次切分，不产生空句；
3. 单个半角连字符 `-` 不切分，避免拆坏英文单词、负数和日期；
4. 句首、句尾的 `--` 直接丢弃，不产生空句；
5. 切分后逐句去除首尾空白，空句丢弃；
6. 不因长短额外切句，也不合并相邻短句。

### 6.3 句内四个空格

在每个句子内部，以下标点后插入四个半角空格：

- 中文：`，`、`、`、`；`、`：`
- 英文：`,`、`;`、`:`

执行细则：

1. 只在该标点后仍有内容时插入；
2. 若标点后原本已有空格，统一替换为**恰好四个**，不叠加；
3. 若标点紧跟右引号、右括号等收尾符号（`”`、`’`、`）`、`)`、`】`、`》`），
   四个空格加在收尾符号之后，例如：`他说：“好的，”    然后转身离开。`；
4. 句末标点后不加四个空格，因为该处已经切句并空行；
5. 以下位置不插入，避免破坏语义：
   - 数字中的千分位逗号，如 `1,000`；
   - 时间、比例、网址中的冒号，如 `12:30`、`1:2`、`https://`；
   - 英文缩写、代码、文件名中的标点；
   - 标点位于句末且后面没有内容。

### 6.4 组装

1. 按原顺序用 `\n\n` 连接所有句子；
2. 文件末尾保留一个换行符即可，不额外追加空行；
3. 不添加任何前后缀说明文字。

## 7. 输出模板

```text
第一句，    逗号后四个空格。

第二句；    分号后四个空格，    继续。

第三句
```

说明：模板只展示排版效果，实际 txt 中不含“第一句/第二句”等编号。

## 8. 示例

输入：

```text
大家好，欢迎来到我的频道。今天聊一个很多人关心的问题--为什么你拍的视频没人看？先说结论，问题不在设备，而在开头。
```

输出 txt：

```text
大家好，    欢迎来到我的频道。

今天聊一个很多人关心的问题

为什么你拍的视频没人看？

先说结论，    问题不在设备，    而在开头。
```

处理说明：

- `--` 处切成两句，并删除 `--`；
- 第一段在 `--` 前原本没有句末标点，**不补标点**；
- `，` 后统一为四个半角空格；
- 句间只有一个空行。

## 9. 边界情况

- **原文无标点**：不按固定字数硬切；只有 `--` / `——` 时按语义切，否则整段作为一句；
- **连续标点**：如 `？！`、`。。。`，按一个句末边界处理，标点原样保留；
- **省略号**：位于句末或后面跟空白时切句；句中省略号后仍有文字时，按句内停顿加四个空格；
- **引号内标点**：逗号在引号内时，四个空格加在右引号之后；
- **数字与网址**：千分位、时间、比例、URL 中的标点不插空格、不切句；
- **`--` 与减号**：只处理两个及以上连续连字符；单个 `-` 保持原样；
- **空输入**：返回“未收到有效口播文案”，不生成空文件；
- **超长文本**：仍按句切分，不做摘要、不截断。

## 10. 验收清单

- [ ] 输出为 UTF-8 `.txt`，文件内无标题、编号、统计或 Markdown 标记；
- [ ] 每句独占一段，句间恰好一个空行；
- [ ] `。！？!?` 等句末标点保留；
- [ ] `--` / `——` 已作为切句点并删除；
- [ ] 每个 `，、；：` 与 `,;:` 后恰好四个半角空格；
- [ ] 数字、时间、URL 中的标点未被误加空格；
- [ ] 原文无增删（仅删除 `--` / `——` 分隔符），顺序不变；
- [ ] 空句、首尾空白已清理；
- [ ] 聊天回复只给路径与句子数、字数。

## 11. Agent 集成建议（可选）

该技能是确定性排版，不需要调用模型。建议新增纯函数：

```python
split_script_to_txt(
    script: str,
    output_dir: str | None = None,
    space_width: int = 4,
) -> tuple[str, int]:
    # 返回 (txt 文件绝对路径, 句子数)
```

职责：

1. 用正则完成切句、删除 `--`、标点后补四个空格；
2. 写入 `state/output/script_split_YYYYMMDD_HHMMSS.txt`；
3. 返回路径与句子数，由通道回传用户；
4. 只依赖 `app/config` 的路径配置，不依赖具体通道。
